MLP 学习参数的实现与可视化

人工智能概论 · 第二篇第 15 节「人工神经元网络」 · 苏州大学 数据科学与大数据技术

1. 实验目标与网络结构

XOR 是经典的非线性可分问题：一条直线无法把 (0,0)、(1,1) 与 (0,1)、(1,0) 分开。本实验用含 2 个隐藏单元的多层感知机学习 XOR，观察参数如何从误差中被逐步调整出来。

项目设置
网络结构2 → 2 → 1（输入 2 维，隐藏 2 单元，输出 1 个 logit）
激活函数Sigmoid
损失函数BCE-with-logits（二元交叉熵）
优化器Adam（手写，含偏差校正）
反向传播手写解析梯度，链式法则

3. 训练过程

本次实际运行中，第 5 次初始化（seed = 46）收敛成功，共训练 1283 轮；在第 85 轮首次实现四个样本全部分类正确，最终损失降至 9.99e-4。

5. 隐藏空间

两个隐藏单元把原本线性不可分的四点映射到新的二维空间。在这个空间里 (0,1) 与 (1,0) 几乎重合，四个点变得线性可分——这正是隐藏层的作用。

7. 核心代码

前向传播与反向传播（点击展开） 
# 前向
h = sigmoid(X @ W1 + b1)          # (4,2)
z = h @ W2 + b2                   # logits (4,1)

# 反向（BCE-with-logits 的解析梯度）
dz  = (sigmoid(z) - Y) / len(X)   # dL/dz
dhp = (dz @ W2.T) * h * (1 - h)   # 隐藏层梯度

g_W2 = h.T @ dz
g_b2 = dz.sum(0, keepdims=True)
g_W1 = X.T @ dhp
g_b1 = dhp.sum(0, keepdims=True)
Adam 参数更新（点击展开） 
m[k] = beta1 * m[k] + (1 - beta1) * g[k]
v[k] = beta2 * v[k] + (1 - beta2) * g[k] ** 2
mhat = m[k] / (1 - beta1 ** t)
vhat = v[k] / (1 - beta2 ** t)
P[k] -= lr * mhat / (sqrt(vhat) + eps)

8. 结论

  • 只有 2 个隐藏单元，网络就能学会 XOR，说明非线性激活带来的表达能力是关键。
  • "学习参数"的本质是最小化二元交叉熵：梯度从输出层逐层回传，Adam 依据一阶、二阶动量调整每个权重与偏置。
  • 从损失曲线看，第 85 轮已全部分类正确，但 loss 仍在持续下降——分类正确与概率置信度是两件事。
  • 训练存在随机性：本次第 5 次初始化才收敛，因此早停与多次重启对稳定性很重要。
